# 정산 시스템 요구사항 정의서

## REQ-SETTLEMENT-REFUND-409 중복 정산 취소 방지

주문 시스템이 이미 처리된 환불임을 알리면 정산 시스템은 동일 거래의 취소 분개를 추가 생성하지 않는다.

### 업무 규칙

- 주문·환불 식별자 조합으로 기존 정산 취소 반영 여부를 확인한다.
- 이미 반영된 거래는 멱등 성공으로 처리한다.
- 미반영 거래만 취소 분개 생성 대상으로 처리한다.
- 판정 근거가 불충분하면 자동 반영하지 않고 확인 필요 상태로 남긴다.
